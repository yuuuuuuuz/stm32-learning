# STM32 学习仓库

跟随江协科技 STM32 入门教程的练习工程记录（STM32F103C8T6 + 标准外设库）。

## 工程列表

| 文件夹 | 内容 |
|---|---|
| 2-1 STM32工程模板 | 标准库工程模板（Start / Library / User / System） |
| 3-1 LED闪烁 | GPIO 输出：点亮 LED |
| 3-2 LED流水灯 | GPIO 输出：LED 流水灯 |
| 3-3 蜂鸣器 | GPIO 输出：有源蜂鸣器 |
| servo-pwm | GCC + Makefile 构建，舵机 PWM 实验 |

## 说明

- Keil 工程直接双击各文件夹内的 `project.uvprojx` 打开
- 编译产物（Objects / Listings 等）已通过 `.gitignore` 过滤
